# BUG-1: Фильтры каталога сбрасываются после перехода на карточку и возврата назад

**Затронуто:** /spells/, /backgrounds/, /feats/, /bestiary/, /items/
**Окружение:** Vivaldi (Chromium), Linux Mint, дата: [3.11.26]; автотест: Playwright Chromium
**Серьёзность:** [Низкая]
**Путь к автотесту** /playwright/filters/test_filters_back.py
## Шаги
1. Открыть раздел (например, https://dnd.su/spells/).
2. В фильтре «Уровень» выбрать «2». Список сокращается.
3. Открыть любую запись из списка.
4. Нажать «Назад» в браузере.
5. Сравнить числа

## Ожидаемый результат
Фильтр сохранён, список остаётся отфильтрованным.

## Фактический результат
Поле фильтра пустое (`[]`), список снова полный.
